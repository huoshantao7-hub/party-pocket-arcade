# 霓虹气垫球

双人同屏复古竞技。青绿与粉红球拍各守半场，将冰球打进对方侧边球门；60 秒内得分高者获胜，率先进 7 球提前结束。墙壁会反弹，球拍速度会影响击球速度。双方移动、冲刺能力完全相同。

P1：WASD 移动、F 冲刺、G 稳住；P2：方向键移动、K 冲刺、L 稳住。触屏通过方向盘和动作键使用相同机制。冲刺持续 0.23 秒，冷却 2.25 秒；稳住降低移动速度，方便防守。

实现：纯 Canvas 原创矢量美术，固定种子、分步冰球碰撞、半场约束、侧墙球门、真实计分、粒子与拖尾。单人/演示机器人通过普通玩家输入控制，得分来自物理碰撞，没有预设赢家。测试专用状态注入只在显式 debug 选项下出现。

## 推文

把小时候的街机气垫球，装进浏览器了 🏒

两个人一人守一边：冲刺抢球、贴墙反弹、门前救险，60 秒就能打一场。最爽的不是大力出奇迹，而是眼看要丢球，最后一拍反杀。

支持同屏双人，也能和机器人练手。青绿 vs 粉红，你会选哪边？

## 可复现提示词

请用原生 JavaScript 与 Canvas2D 制作原创双人浏览器游戏「霓虹气垫球」。画布 960×600，深蓝球场、青绿与粉红球拍、发光冰球、网格地板、圆形开球区、球门网、碰撞粒子与短拖尾。P1 用 WASD/F/G，P2 用方向键/K/L；方向移动，主动作短冲刺，副动作精确慢移。每人限于自己半场，使用圆形球拍和圆形冰球的真实碰撞，球拍移动速度传给球，边墙反弹，左右球门进球计分。每局 60 秒或率先 7 球，平局真实显示。提供可重置固定种子、普通输入驱动的机器人、暂停、音效开关与移动端双人按键。禁止脚本预设输赢。编写半场边界、球门/边墙区分、碰撞反弹、冲刺、胜利冻结、确定性测试。

## 测试

规则测试见 `tests/hockey.test.mjs`。在仓库根目录运行 `npm test`。测试包括确定性、独立玩家控制、真实计分与结算冻结；具体机制以测试用例为准。

# 泡泡爆破

原创水族馆主题的复古爆破对战。方向键走格子，动作键放泡泡：2.1 秒后沿十字方向爆破，墙会阻挡，遇到第一只箱子即停止并破箱。泡泡可引发连锁爆破。自己放的泡泡允许离开，但不能重新走进去。初始容量 1、范围 2，拾取道具最高容量 3、范围 4。

破箱 +4 分，拾取道具 +3 分。某方被爆破击中，存活方 +40 分并进入下一回合；双方同时被击中则不加回合分。75 秒按总分结算。护盾持续 0.75 秒、冷却 7 秒。地图外圈保持连通，出生处保留逃生走廊。

P1：WASD / F 放泡泡 / G 护盾；P2：方向键 / K 放泡泡 / L 护盾。支持手机方向键。同屏两人，或单人对规则机器人；机器人只通过相同输入接口操作，先规划逃生路线再放泡泡。

## 推文

把小时候爱玩的迷宫爆破，做成了双人「泡泡爆破」🫧

放泡泡、拆箱子、捡道具，再用连锁爆破封住朋友的退路。还加了一个短暂护盾：按早了浪费，按晚了直接下一回合 😂

原创水族馆画风，一局 75 秒。同屏双人，也能和机器人练手。最危险的，往往是自己刚放下的那颗泡泡。

## 复现提示词

用原生 JavaScript ES 模块和 Canvas 2D 制作原创复古同屏双人游戏《泡泡爆破》，不要复制现有游戏角色或素材。960×600 水族馆画布，11×9 地图，固定墙、随机可破坏箱子、透明彩色泡泡、带潜水镜和表情的小鱼角色。出生走廊与外圈始终连通。方向键移动，每格约 0.14 秒；动作键放泡泡，2.1 秒后十字爆破，墙挡住，箱子挡住并破坏，可连锁引爆。初始容量 1、范围 2，可通过道具提升。破箱 +4、道具 +3、回合存活胜方 +40；同时被炸不加回合分；75 秒总分判胜，自动重开小回合。副动作开启 0.75 秒护盾，冷却 7 秒。实现键盘和手机方向键、同屏双人和真实规划逃生的非作弊机器人，明确展示模式。种子确定性、结束冻结、计分真实。绘制泡泡折射渐变、爆破光环、粒子、角色游动等动态画面。测试碰撞、出生逃生、容量、离开泡泡不能重入、十字阻挡、连锁爆破、盾、计分和平局。

# 午夜外卖

75 秒双人合作厨房。每一份星光热面都经过真实的取料、备菜、煮面与出餐过程。画面采用暖木色地砖、薄荷绿与桃粉色厨师、冒热气的面碗和柔和台面阴影；所有角色与道具由 Canvas 绘制，不依赖外部图片。

## 怎样玩

1. P1 用 WASD 移动、F 互动、G 直接递给搭档；P2 用方向键移动、K 互动、L 直接递给搭档。手机方向键及互动按钮对应相同逻辑。
2. 靠近左侧蔬菜仓，互动取料；到左上备菜台放下，等待 2.1 秒后互动取回。
3. 可以在中间接力台放下切好的食材，搭档空手互动取走；两人相距不足 92 像素时也能直接递菜。
4. 到右上炉灶放入切好的食材，煮 2.8 秒后端走，到右侧外卖窗口互动出餐。
5. 每碗基础 100 分，跨玩家接力额外 40 分，连续完成订单最高另加 40 分。接力分由两位厨师平分，记分板显示各自贡献，两人相加等于团队分。
6. 每份订单有 24 秒耐心；过时会更换新订单并清空连单奖励，手中的食材保留。一局 75 秒，适合重复挑战合作总分。

两位厨师都能完成所有操作。推荐一人备菜、一人煮面出餐，使用接力台减少走动。单人模式由规则机器人操作 P2；自动展示时双方均由机器人控制。机器人通过正常移动和互动输入完成游戏，没有直接修改分数或食材。

## 配套推文

把夜宵摊做成了一个双人小游戏：**午夜外卖** 🍜

一个人取料切菜，一个人煮面出餐。75 秒打烊倒计时，明明只想递碗面，最后却变成：

“菜呢？”“在你后面！”“别拿我的锅！！”

我还加了接力奖励——这次高分靠的真是默契。

支持同屏双人，也能让同一 Wi-Fi 下的手机当手柄。没人陪？先和机器人练一局。

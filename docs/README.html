GET THE PARTY STARTED

一分钟，马上开局。

六款原创小游戏，每款都能单人陪练、同屏双人或观看机器人自动展示。没有注册和内购，所有运行资源都在本地。

一台电脑，两个人玩

打开任意游戏，选择“同屏双人”，然后开始。P1 用 WASD 移动、F/G 动作；P2 用方向键移动、K/L 动作。每款的具体动作在右侧说明栏。

手机当手柄

  1. 电脑进入游戏，点击“创建双人房间”。
  2. 手机与电脑连同一 Wi-Fi，打开房间显示的局域网链接。
  3. 选择 P1 或 P2 加入。手机控制角色，电脑显示游戏。

支持一台电脑＋一部手机，或两部手机控制。不是公网远程联机。独立浏览器通信测试通过，实体手机跨 Wi-Fi 尚未验证；设备互通取决于主机防火墙和路由器设置。

一个人，照样尽兴

选“单人 + 机器人”，你控制 P1。选“自动展示”可以先观察玩法；它明确由规则机器人操作，得分仍按实际游戏规则产生。

源码启动

Windows 双击“启动街机口袋.cmd”，或在目录运行下面的命令。需 Node.js 20 或更新版，无需安装 npm 依赖。

node server.mjs
http://127.0.0.1:8770

# 云顶快递 · Cloud Courier

一个原创的横版跳跃闯关小游戏：邮递员穿过三座浮岛，收集金币、顶起问号砖、躲开或踩倒小怪，把包裹送到终点邮局。

平台跳跃玩法借鉴经典横版游戏；角色、关卡与 Canvas 画面为本项目原创。模型控制通过本地 [NandhaKishorM/laya](https://github.com/NandhaKishorM/laya) 接入，手动玩法与规则演示不需要模型。

## 启动

1. Windows 双击 `启动游戏.cmd`，在浏览器打开 `http://127.0.0.1:8785`。
2. 选“我来玩”直接开始；想先看路线，选“看演示 · 规则机器人”。
3. 关卡卡片可以直接选择三关，通关后也能进入下一站。

启动器会优先复用已配置的 `LAYA_PYTHON` 或同级旧 Laya 项目的 Python；否则使用已安装的 Python。手玩和规则模式只需要 Python 标准库。也可以运行：

```powershell
python -B launch.py
```

服务只监听本机 `127.0.0.1`。手机触控界面已在浏览器仿真中验证；当前启动配置没有对局域网公开，不要把手机模拟器测试理解为已完成真实手机联机。

## 操作与玩法

| 操作 | 键盘 | 屏幕按钮 |
|---|---|---|
| 左右移动 | ← / → | 左 / 右 |
| 跳跃 | 空格；长按跳得更高 | 跳跃；可以长按 |
| 加速 | Shift | 加速 |
| 暂停 / 继续 | P 或页面按钮 | 暂停 / 继续 |
| 重开当前关 | 页面“重开” | 重开 |

- 问号砖从下方顶起，第一次会给金币；从上方踩敌人可以消灭它，侧面碰撞会受伤。
- 初始三颗心；掉落山谷会扣血。点亮中途旗帜可恢复满血，并让之后的掉落从检查点继续。
- 心数耗尽后本关失败，可以重来；抵达终点邮局后结算金币、分数和实际用时。
- 暂停、窗口失焦或页面隐藏都会停止当前游戏并清理按键；重开与切关也不会保留旧输入。
- 手机竖屏使用底部触控；低高度横屏把触控安排在画面两侧，让场景与操作键同屏。

三关分别是 **晴空邮路、落日汽水厂、星灯云港**，拥有不同的配色、平台、峡谷、金币路线与敌人。

## 三种模式务必分清

| 模式 | 谁在控制 | 已验证范围 |
|---|---|---|
| 手动闯关 | 键盘或屏幕触控 | 实际按下/松开、移动、跳跃、暂停和重开 |
| 规则机器人演示 | 项目内明确标注的规则逻辑 | 三关通过正常游戏输入零死亡到达终点 |
| Laya 本地模型 | 真实本地模型返回 typed decision | 本机真实 CPU 推理可用；不等于已证明能够通关 |

规则演示的三关通关成绩不能当作 Laya 成绩。Laya 模式是实验性玩法，未针对本游戏训练。本机首轮 4 次真实 CPU 调用耗时约 2.1–3.5 秒，动作全部为 wait；随后浏览器 UI 验收的两次真实调用为约 5.45 / 4.34 秒，也均为 wait。这些是本机少量实测，不是稳定延迟基准，因此不能宣称模型已经会玩或能通关。它可能等待、碰撞或掉落，系统不会用规则纠正来伪造模型能力。

## 本地 Laya

点击“加载本地 Laya”或直接开始 Laya 模式。第一次加载可能较慢；本机首次记录约 **2 分 20 秒**。页面会显示加载状态，推理开始后显示真实动作、推理耗时、置信度和决策次数。耗时以本次界面值为准，没有预填毫秒级成绩。

模型未就绪、超时或调用失败时，会明确显示错误或暂停；不会悄悄换成规则机器人。

本项目不包含模型权重，也不会自动下载模型或访问云 API。启动器可以读取既有的同级 `laya_asteroid_benchmark` 安装，或本项目 `.local/laya` 下的安装；也可自行设置：

- `LAYA_SOURCE_PATH`：上游源码根目录，里面包含 `laya/`。
- `LAYA_MODEL_PATH`：完整模型目录，包含权重、配置、tokenizer 和 encoder。
- `LAYA_PYTHON`：已经安装相应 AI 依赖的 Python 可执行程序。

详细接口、取消机制和本地目录要求见 `docs/ai-api.md`；AI 依赖列表见 `requirements-ai.txt`。不需要提供密码、Cookie 或云 API 密钥。

## 结构与复现

- `index.html` / `style.css` / `app.js`：界面、输入、三种模式和生命周期。
- `engine.js` / `levels.js`：固定步长物理、碰撞、奖励与三关地图。
- `renderer.js` / `sound.js`：原创 Canvas 绘制与本地合成提示音。
- `server.py`：静态页面和真实 Laya 接口；本地模型错误不会返回替代动作。
- `tests/`：引擎规则与后端边界测试。
- `制作提示词.md`：可以交给编码助手复现的完整需求。

运行引擎和服务测试：

```powershell
node --test
python -B -m unittest discover -s tests -p test_server.py -v
```

项目源码已收入街机口袋开源仓库；Laya 模型权重与上游源码需另行获取。

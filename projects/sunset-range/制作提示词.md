# 落日靶场：可复用制作提示词

将下方内容交给具备本地文件编辑能力的编程助手。它描述玩法和验收标准；运行结果仍需实际测试，不能只交一张界面图。

---

制作一个可玩的原创浏览器小游戏《落日靶场 · Sunset Range》。不使用外部游戏素材或商业游戏角色，不接云 API、AI 模型或账号系统。

**视觉与结构**

使用 HTML、CSS 和原生 JavaScript ES Modules。Canvas 呈现有纵深的落日靶场、移动圆靶、红色靶心和少量金色奖励靶；采用深青灰、暖沙色与落日橙的配色，清晰大号数字、圆角面板和克制的光影。让靶子、开火反馈、命中粒子与换弹提示持续运动，避免把游戏做成幻灯片。原创 Web Audio 音效可开关。布局包含主游戏区域、得分/时间/弹药 HUD、模式与装备设置、结果面板；适配桌面及触屏屏幕。

**三种真实可玩模式**

1. 单人高分挑战：60 秒，结束后结算；本机最佳成绩按武器分别保存，中途换枪的混合武器局不入榜。
2. 自由练习：不限时，允许暂停、重开。
3. 同机轮流对决：两名玩家各 30 秒；赛前选定同一武器后锁定，两轮使用相同随机种子，中场必须由交接按钮启动第二轮，比较真实得分。不要称为联机或同时对战。

**两种装备**

- 星火手枪：8 发弹匣、射击间隔 0.25 秒、换弹 1.1 秒；每次按下只射一发。
- 流光连发器：18 发弹匣、射击间隔 0.10 秒、换弹 1.6 秒；允许按住连发。
- 冷却、换弹、子弹消耗必须由引擎约束，不能通过高频事件绕过。切枪会清空弹匣并完整换弹，避免切枪补弹套利。空枪不增加真实射击次数。

**判定与计分**

包含真正静止的固定靶、左右移动的横移靶和上下移动的升降靶；用坐标和圆形半径进行真实命中检测，画面与判定一致；若重叠，按可见遮挡顺序决定击中的靶。靶心范围为半径的 22% 以内，基础 100 分；中环为 55% 以内，60 分；其余有效靶面 30 分。金色靶得分乘 2。每 5 连击使倍率增加 0.5，最高 3 倍；真实打空或漏过到期靶会清零连击，漏靶不增加射击次数。靶子出现和消失阶段不可击中，退出 0.35 秒后再生。计时须按模拟时长准确结束，不允许暂停期间继续扣时。

**输入与回合**

鼠标移动瞄准、点击开火，步枪可按住连发；触屏轻点靶子射击，拖动只瞄准，提供独立开火和换弹按钮。键盘空格开火、R 换弹、1/2 切枪、P 或 Escape 暂停/继续。暂停、失去页面焦点、重开和结算时清理按住状态，避免返回页面后自动开火。双人局锁定装备并显示当前玩家。记录得分、发射数、命中率、靶心命中数和最高连击，真实计算结算与胜负。

**本地启动**

Python 标准库服务仅绑定 127.0.0.1:8786；GET /api/health 返回 {"service":"sunset-target-range"}。静态白名单仅允许 index.html、style.css、app.js、renderer.js、engine.js、sound.js、favicon.svg。拒绝其他路径、目录遍历及非本机 Host，不公开源码目录、文档或测试。提供 launch.py、launch.ps1 和启动游戏.cmd；Windows 服务器后台隐藏窗口，支持 --no-browser。不硬编码个人机器路径；允许环境变量指定 Python。网页运行不需要 npm 或 pip 依赖。
